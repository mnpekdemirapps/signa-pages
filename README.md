# Signa Pages

Static marketing, support, privacy, and terms pages for **Signa: Math Puzzle**.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages** in `mnpekdemirapps/signa-pages`.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. The expected URL is `https://mnpekdemirapps.github.io/signa-pages/`.

No build step, dependencies, analytics, cookies, external fonts, or JavaScript are used by this website.

## Files

- `index.html` — English marketing and support page
- `index-tr.html` — Turkish marketing and support page
- `privacy.html` / `privacy-tr.html` — English and Turkish privacy policies
- `terms.html` / `terms-tr.html` — English and Turkish terms of use
- `styles.css` — shared responsive styles

## Before release

The legal pages are a product-specific starting point, not legal advice. Have qualified counsel review them before publishing the app, especially the privacy disclosures, age positioning, consumer-law language, advertising/consent flow, and international data transfers. Update the pages whenever the app's SDKs, data practices, purchases, or business details change.
